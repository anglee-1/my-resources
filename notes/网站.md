## 九、实用工作流与快捷键

### 📺 视频解析与转写工作流
1. 复制视频网址，放入 [① Parsevideo](https://pv.vlogdownloader.com/) ，复制解析内容。
2. 放在 [② 通义听悟](https://tingwu.aliyun.com/home) 的“播客链接转写”中，解析视频并开始转写。

### 🧠 思维导图生成工作流
1. 批量摘取复制内容放在 [③ 腾讯元宝](https://yuanbao.tencent.com/) 中，使用提示词：“帮我将以下内容整理成 markdown 格式的层级式思维导图”。
2. 复制生成的代码，放在 [④ markmap](https://markmap.js.org/repl) 中直接渲染。

### ⌨️ Windows 常用快捷键
- `Win + D`：全屏退至桌面
- `Win + G`：游戏监视 / 录屏
- `Win + L`：睡眠 / 锁屏
- `Win + R`：运行
- `Win + I`：设置
- `Win + ↑` / `Win + ↓`：最大化 / 最小化
- `Shift + 6`：打出省略号
- `Shift + F5`：从当前位置放映
- `Ctrl + W`：关闭当前窗口
- `Ctrl + S`：保存
